# Sott

Интернет-магазин мужской одежды, создаваемый с помощью ChatGPT и Codex.

План: каталог, карточки товаров, корзина, сохранение заказов в PostgreSQL, уникальная ссылка заказа, отправка ссылки через WhatsApp и закрытая административная панель.

## Фотографии товаров

В development можно включить локальное хранение через `PRODUCT_STORAGE=local`. В production фотографии должны храниться на постоянном диске: подключите Railway Volume и задайте `UPLOADS_DIR` абсолютным путём к каталогу на этом Volume. В PostgreSQL сохраняется только публичный URL вида `/uploads/products/<random-name>`, а не содержимое файла и не внутренний путь Volume.
